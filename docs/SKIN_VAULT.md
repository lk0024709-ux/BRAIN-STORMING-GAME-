# Battle Dojo Skin Vault — asset + prompt pack

Everything the shop needs for the six polygon skins is generated, committed, and
wired into the Flutter app. This file is the contract between the art pack, the
generator script, and the game code.

Fixed style rules from the pack:

* 512×512 PNG, transparent background, centered character bust.
* Glowing rarity border, **8 px** at 512 px.
* Dark space `#0A0E1A` panel with a low-poly neon wireframe grid
  (`#00FFFF` / `#8A2BE2`) and a per-rarity pattern inside the polygon.
* Top row: `Lv.12` chip + coin balance chip, plus a `#FF0000` heart when the
  tier carries one.
* Skin name under the frame, price in coin yellow `#FFD700` with the word
  `coin`, and a `BUY` bar — or the green `EQUIPPED` state.

Files:

```
assets/skins/raw/                       source art straight from the image model (1024×1024)
assets/skins/cards/<skin>.png           store card, BUY state           (512×512)
assets/skins/cards/<skin>_equipped.png  store card, EQUIPPED state      (512×512)
assets/skins/busts/<skin>.png           transparent bust for the hero portrait
assets/skins/store_config.json          generated style guide + store JSON
tools/generate_store_assets.py          the generator (Pillow + numpy)
tools/preview_skin_cards.png            contact sheet of all six BUY cards
```

## Prompt pack used for the busts

The busts were generated by re-theming the app's existing hero portrait, so the
face stays on-model in every skin. The shared tail of every prompt enforces the
manga look and the transparent-PNG hand-off:

> Manga anime game character bust portrait, same spiky black-haired teen hero
> style as the reference image, now re-themed as a **<SKIN THEME>** … chest-up
> centered portrait facing viewer, fully inside frame with clean margin. Thick
> black ink outlines, bold cel shading with halftone dot screentone, vivid
> saturated colors, neo-brutalist sticker look. Plain flat pure white
> background, no text, no letters, no numbers, no frame, no border, no
> watermark, single centered character only, square 1:1 composition.

Per-skin theme clause:

* **Neon Ninja** — black hooded shinobi head wrap, glowing cyan neon trim
  `#00FFFF`, cyan glowing visor band over one eye, confident smirk.
* **Cyber Samurai** — layered samurai shoulder armor with tech circuit etching,
  neon purple `#8A2BE2` energy trim, purple visor, katana hilt over the shoulder.
* **Shadow Assassin** — dark hooded cloak, face half in shadow, glowing magenta
  `#FF00FF` eyes, purple smoke wisps behind the shoulders.
* **Frost Warrior** — ice-blue plated armor with frost shard spikes, glowing
  `#00BFFF` runes, frost crystals and cold mist.
* **Inferno Mask** — red oni mask pushed up on the forehead, cracked armor with
  lava glow seams, `#FF4500` flame particles, ember eyes.
* **Golden Emperor** — gold `#FFD700` plated armor with ornate engravings, crown
  circlet, fur-trimmed cape collar, halo of gold light rings.

### Negative prompts

Use these when you re-run the busts on a raw diffusion pipeline (Replicate,
ComfyUI, Automatic1111, Leonardo). They are not needed for the card step — the
generator draws the frames itself.

**Stable Diffusion / ComfyUI / A1111**

```
negative: text, letters, numbers, watermark, signature, logo, frame, border,
card, ui, hud, badge, coin, heart, lowres, blurry, jpeg artifacts, extra
fingers, extra arms, extra head, deformed face, asymmetric eyes, mutated hands,
bad anatomy, cropped head, head cut off, off-center, multiple characters,
characters, crowd, background scenery, gradient background, colored background,
3d render, photorealistic, photo, blurry lines, messy lineart, sketch,
greyscale, desaturated, muted colors, sepia
```

**Replicate (`negative_prompt` field)**

```
negative_prompt: text, watermark, frame, border, ui elements, multiple people,
cropped, deformed, extra limbs, realistic photo, 3d, low quality, blurry,
colored background, scenery
```

**Midjourney / Leonardo (inline)**

```
--no text, letters, numbers, watermark, frame, border, card, ui, multiple
characters, background scenery, 3d, photorealistic, deformed face, cropped
--style raw --ar 1:1
```

Keep the flat white background: `tools/generate_store_assets.py` keys it out with
a corner flood-fill, so a busy or gradient backdrop leaks into the cutout.

## Regenerating the assets

```bash
python3 -m pip install Pillow numpy        # or a venv
python3 tools/generate_store_assets.py
```

The script re-renders `assets/skins/cards/`, `assets/skins/busts/`,
`assets/skins/store_config.json` and the contact sheet. Point it at new source
art with `SKIN_RAW_DIR=/path/to/1024px_pngs`. Prompts, prices, colours and frame
shapes all live in the `SPEC` + `SHAPES` tables at the top of the script — edit
those, not the rendered PNGs.

## Wiring in the game

* `assets/skins/store_config.json` is the source of truth for the art pack.
* `lib/models/skin_shop.dart` (`SkinCatalog`) is the runtime mirror; the shop
  reads prices, borders and hearts from it, and `test/skin_shop_test.dart`
  asserts the JSON and the Dart table are identical.
* `lib/widgets/skin_card.dart` renders one store card at any size.
* `ShopScreen` shows the vault; buying deducts coins, equipping swaps the hero
  portrait on `HomeScreen` (`assets/skins/busts/<skin>.png`).
* Owned skins persist in `SharedPreferences` (`owned_skins`, `equipped_skin`)
  and survive a training reset.

## Importing into Unity / React instead

The cards are plain transparent PNGs, so they drop into any engine:

* **Unity** — put the files under `Assets/StreamingAssets/skins/`, import with
  `Texture Type: Sprite (2D and UI)`, `Alpha Is Transparency: true`,
  `Filter Mode: Bilinear`, and slice nothing (each card is self-contained).
* **React/web** — reference `assets/skins/cards/<skin>.png` directly; the cards
  already contain the frame, rarity tag, price and BUY bar, so a `<img>` is
  enough. Use `_equipped` for the owned state.
* Money text is baked as `#FFD700` and hearts as `#FF0000`, matching the
  `coin_color` / `heart_color` keys in the JSON if you would rather draw those
  in-app.
